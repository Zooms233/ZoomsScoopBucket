# ZoomsScoopBucket

个人 Scoop bucket，收录官方 Scoop 仓库未收录的实用软件。

## 使用方法

```powershell
scoop bucket add zooms https://github.com/Zooms233/ZoomsScoopBucket
scoop install <app-name>
```
